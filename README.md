# MetroSync Backend

Real-time metro announcements backend built with Node.js, Express, MongoDB, JWT, and Socket.io.

## Features

- MongoDB Atlas database
- Station management
- Admin authentication
- bcrypt password hashing
- JWT authentication
- Protected admin routes
- Announcement CRUD operations
- Pagination
- Input validation
- Login rate limiting
- Socket.io station rooms
- Real-time announcements
- Real-time viewer tracking
- Jest and Supertest integration tests
